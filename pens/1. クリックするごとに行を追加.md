# innerHTMLを使用する場合
```html
<button id="add-btn">1行追加</button>

<table border="1">
  <tbody>
    <tr>
      <td></td>
      <td></td>
    </tr>
  </tbody>
</table>
```

```js
// 1. 変数名「addBtn」では、HTMLのid名「add-btn」を取得
const addBtn = document.getElementById("add-btn");
// 2. 変数名「table」では、HTMLのCSSセレクタ「table」を取得
const table = document.querySelector("table");
// 3. 変数名「tbody」では、HTMLのCSSセレクタ「tbody」を取得
const tbody = document.querySelector("tbody");

// ===== 行を追加する関数 =====
function addRow() {
  console.log("クリックされました");

  // (3)に値を設定する
  tbody.innerHTML += `  <tr>
      <td></td>
      <td></td>
    </tr>
  `;
  console.log(table.outerHTML);
}

// ➀の変数名「addBtn」がクリックされたときに、関数「addRow」を実行する
addBtn.addEventListener("click", addRow);

// => <table border="1">
// =>   <tbody>
// =>     <tr>
// =>       <td></td>
// =>       <td></td>
// =>     </tr>
// =>     <tr>
// =>       <td></td>
// =>       <td></td>
// =>     </tr>
// =>   </tbody>
// => </table>
```

## 失敗バージョン

- ### `tbody` が入ってしまう
  原因：HTMLに `<tbody>` を入れずに、`<table>` に追加すると自動で `<tbody>` が入ってしまう
  ```html
  <button id="add-btn">1行追加</button>

  <table border="1">
    <tr>
      <td></td>
      <td></td>
    </tr>
  </table>
  ```

  ```js
  // 1. HTMLのid名「add-btn」を取得
  const addBtn = document.getElementById("add-btn");
  // 2. HTMLのCSSセレクタ「table」を取得
  const table = document.querySelector("table");

  // ===== 行を追加する関数 =====
  function addRow() {
    console.log("クリックされました");
    table.innerHTML += '<tr><td></td><td></td></tr>';
    console.log(table.outerHTML);
  }

  // ➀の変数名「addBtn」がクリックされたときに、関数「addRow」が実行される
  addBtn.addEventListener("click", addRow);

  // => <table border="1">
  // =>   <tbody><tr>
  // =>     <td></td>
  // =>     <td></td>
  // =>   </tr>
  // => </tbody><tbody><tr><td></td><td></td></tr></tbody></table>
  ```
  <!-- demo
  ```css

    border-collapse: collapse;
    width: 100px;
    border: 1px solid black;
    margin-top: 10px;
  }

  td {
    height: 20px;
  }
  ```
  -->


- ### コード整形して入れたいけど、エラー
  原因：シングルクォート `'...'` では、文字列の途中でそのまま改行できない
  ```js
  tbody.innerHTML += '<tr>
    < td ></td >
      <td></td>
  </tr >
    ';
  ```
