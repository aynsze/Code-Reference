# 今日の日付を取得

## 1. 基本

```js
// 年を取得
const year = new Date().getFullYear();
// 月を取得（⚠ 今月を求めるには、+1）
const month = new Date().getMonth() + 1;
// 日を取得
const day = new Date().getDate();
// 曜日を取得（⚠ 日曜日が0）
const dayIndex = new Date().getDay();

console.log(`${year}年${month}月${day}日${dayIndex}曜日`);
// => 例：2026年10月22日4曜日
```

## 2. 曜日は数値で返されるため、配列を利用する

```js
// 曜日を取得（⚠ 日曜日が0）
const dayIndex = new Date().getDay();

// 曜日名の配列（日曜始まり）
const dayNames = ["日", "月", "火", "水", "木", "金", "土"];

// 配列名[変数名]
console.log(`${dayNames[dayIndex]}曜日`);
// => 木曜日
```

# YY/MM/DD形式にする
⚠ 順番に注意  
数値を取得してから、文字列に変換する
1. `getFullYear()`、`getMonth()`、`getDate()` で数値を取得
2. `toString()` または `String()` で文字列に変換
3. `slice()` で年の下2桁を取得し、`padStart()` で月・日を2桁に調整

## 成功バージョン
- ### 方法1
  ```js
  // 例：2026年9月1日
  const date = new Date(2026, 8, 1);


  // 年を取得して、文字列に変換して、末尾2桁を取得
  const year = date.getFullYear().toString().slice(-2);

  // 月を取得して、文字列に変換して、2桁ではない場合は、先頭に「0」を追加して2桁の長さに調整
  const month = (date.getMonth() + 1).toString().padStart(2, "0");

  // 日を取得して、文字列に変換して、2桁ではない場合は、先頭に「0」を追加して2桁の長さに調整
  const day = date.getDate().toString().padStart(2, "0");

  console.log(`${year}/${month}/${day}`);
  // => 26/09/01
  ```
  <!-- demo -->

- ### 方法2
  `slice(2)` でも可能。先頭から2文字を取り除くことで、年の下2桁を取得できる  
  ただし、年の下2桁を取得するという目的が明確な `slice(-2)` のほうがおすすめ
  ```js
  // 年を取得
  const date = new Date();
  const year = date.getFullYear().toString().slice(2);

  console.log(`${year}`);
  // 例：2026 => 26
  ```
  <!-- demo -->

- ### 方法3
  文字列で囲む

  ```js
  // 例：2026年9月1日
  const date = new Date(2026, 8, 1);


  // 年を取得して、文字列に変換して、末尾2桁を取得
  const year = String(date.getFullYear()).slice(-2);

  // 月を取得して、文字列に変換して、2桁ではない場合は、先頭に「0」を追加して2桁の長さに調整
  const month = String(date.getMonth() + 1).padStart(2, "0");

  // 日を取得して、文字列に変換して、2桁ではない場合は、先頭に「0」を追加して2桁の長さに調整
  const day = String(date.getDate()).padStart(2, "0");

  console.log(`${year}/${month}/${day}`);
  // => 26/09/01
  ```

## 失敗バージョン

- ### 文字列で返していない
  ```js
  const date = new Date();
  const year = date.getFullYear().slice(-2);

  console.log(`${year}`);
  // エラー
  ```
  <!-- demo -->

- ### 先に文字列に変換してしまった
  `toString()` で文字列に変換すると、`getFullYear()` は使えない
  ```js
  // 年を取得
  const date = new Date().toString();
  const year = date.getFullYear().slice(-2);

  console.log(`${year}`);
  // エラー
  ```
  <!-- demo -->

- ### 構文エラー
  `1.toString()` は、そのままでは書けない
  ```js
  // 例：2026年9月1日
  const date = new Date(2026, 8, 1);

  // 月を取得して、文字列に変換して、2桁ではない場合は、先頭に「0」を追加して2桁の長さに調整
  const month = date.getMonth() + 1.toString().padStart(2, "0");

  console.log(`${month}`);
  // エラー
  ```
