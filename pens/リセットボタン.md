```html
<input type="text">
<button>リセット</button>
```
<!-- demo -->

## 成功バージョン
```js
// 1. HTMLのinputタグを取得
const input = document.querySelector("input");
// 2. HTMLのbuttonタグを取得
const resetBtn = document.querySelector("button");

// ➁の変数名「resetBtn」がクリックされた時（click）に実行
resetBtn.addEventListener("click", function() {
  // inputの値を空にする
  input.value = "";
});

```

## 失敗バージョン
- `input` の場合、`innerHTML` や `textContent` では、出来ない

  ```js
  resetBtn.addEventListener("click", function() {
    input.innerHTML = "";
  });
  ```
