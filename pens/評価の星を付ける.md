# 評価の星を付ける

以下みたいなのを作成したい
```text
★★★★☆
```

[`文字列.repeat(n)`](../docs/03_1.%20JavaScript_基本.md#繰り返すrepeat)：文字列をn回繰り返す

## 1. ★だけの場合
```js
// 1. 評価の値を定義
const rating = 2;

// 2. ➀の評価の数分、「★」を繰り返す
const star = "★".repeat(rating);

console.log(star);
```
<!-- demo -->

## 2. ★と☆を使用
```js
// 1. 評価の値を定義
const rating = 2;

// 2. ➀の評価の数分、「★」を繰り返す
const star = "★".repeat(rating);

// 3. 残りの数分（星5 - ➀の評価の数）、「☆」を繰り返す
const emptyStar = "☆".repeat(5 - rating);

// ➁と➂を結合する
console.log(star + emptyStar);
```

- 以下でも可能
  ```js
  // 1. 評価の値を定義
  const rating = 4;

  // 2. ➀の評価の数分、「★」を繰り返して、残りの数分（星5 - ➀の評価の数）、「☆」を繰り返す
  const star = "★".repeat(rating) + "☆".repeat(5 - rating);

  console.log(star);
  ```
