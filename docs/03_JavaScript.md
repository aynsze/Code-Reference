# 基本

## メッセージ表示

- ### ダイアログ

  ```js
  alert("Hello");
  ```

- ### コンソール

  ```js
  console.log("Hello");
  ```

  <!-- demo -->

## 文字列出力

- ### 変数を用いる場合

  文字列全体をバッククォート「\`」で囲んで、`${変数名}`

  ```js
  let name = "花子";
  console.log(`こんにちは、${name}です！`);
  ```
