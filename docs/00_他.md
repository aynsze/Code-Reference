## 拡張子

| 言語       | 拡張子  |
| ---------- | ------- |
| HTML       | `.html` |
| CSS        | `.css`  |
| JavaScript | `.js`   |
| TypeScript | `.ts`   |
| Python     | `.py`   |
| SVG        | `.svg`  |
| Markdown   | `.md`   |
| JSON       | `.json` |

## 相対パス
```text
フォルダA/
├── README.md
├── pages/
│   ├── 00.md
│   ├── 22.md
│   └── image/
│       └── demo.md
└── data/
    └── sample.md
```

- ファイル名だけを書く → 同じフォルダ内（例: `22.md`）
    - 相対パスであることを明示したい場合は `./22.md` と書いてもよい
- 下の階層へ行く → フォルダ名を書く（例: `image/demo.md`）
- 上の階層へ行く → `..` を使う（例: `../README.md`）

| 構造    | 内容            |
| ------- | --------------- |
| `.`     | 今いるフォルダ  |
| `..`    | 1つ上のフォルダ |
| `../..` | 2つ上のフォルダ |


| 参照元＼参照先      | README.md         | pages/00.md      | pages/22.md      | pages/image/demo.md      | data/sample.md         |
| ------------------- | ----------------- | ---------------- | ---------------- | ------------------------ | ---------------------- |
| README.md           | -                 | `./pages/00.md`  | `./pages/22.md`  | `./pages/image/demo.md`  | `./data/sample.md`     |
| pages/00.md         | `../README.md`    | -                | `22.md`          | `./image/demo.md`        | `../data/sample.md`    |
| pages/22.md         | `../README.md`    | `00.md`          | -                | `./image/demo.md`        | `../data/sample.md`    |
| pages/image/demo.md | `../../README.md` | `../00.md`       | `../22.md`       | -                        | `../../data/sample.md` |
| data/sample.md      | `../README.md`    | `../pages/00.md` | `../pages/22.md` | `../pages/image/demo.md` | -                      |
