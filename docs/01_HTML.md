# 基本

## 文字系

- ### 強調
  - `<strong>`

    ```html
    テキストを<strong>強調</strong>する
    ```

    <!-- demo -->

  - `<b>`

    ```html
    テキストを<b>強調</b>する
    ```

    <!-- demo -->

- ### 上付き、下付き
  - 上付き：`<sup>`

    ```html
    10の2乗は、10<sup>2</sup>
    ```

    <!-- demo -->

  - 下付き：`<sub>`

    ```html
    水の分子記号は、H<sub>2</sub>O
    ```

    <!-- demo -->
