# イベントリスナー
`イベントの登録先.addEventListener("イベント", 関数名);`

## イベントの登録先
| イベントの登録先 | 対象                   | 例                           | 要素の取得 |
| ---------------- | ---------------------- | ---------------------------- | ---------- |
| `window`         | ブラウザのウィンドウ   | ウィンドウのサイズ変更を監視 | 不要       |
| `document`       | ドキュメント全体       | ページ内のクリックを監視     | 不要       |
| `element` *      | 取得した特定のHTML要素 | 特定のボタンのクリックを監視 | 通常は必要 |

＊`イベントの登録先` に対して、HTML要素を取得した場合は、その要素を格納した `変数名` を指定できる


## 指定方法
- ### 関数名を指定する場合
    ```js
    イベントの登録先.addEventListener("イベント", 関数名);
    ```
    例：ドキュメント全体に対して、関数名を指定
    ```js
    function showMessage() {
      console.log("クリックされました");
    }

    document.addEventListener("click", showMessage);
    ```
    <!-- demo -->


- ### 関数を直接指定する場合
  - 通常の関数（無名関数）
    ```js
    イベントの登録先.addEventListener("イベント", function () {
      関数の内容;
    });
    ```
    例：取得したHTML要素に対して、関数を直接指定
    ```js
    const btn = document.getElementById("button");

    btn.addEventListener("click", function () {
      console.log("クリックされました");
    });
    ```
    <!-- demo 
    ```html
    <button id="button">クリック</button>
    ```
    -->

  - アロー関数（`=>`）
    ```js
    イベントの登録先.addEventListener("イベント", () => {
      関数の内容;
    });
    ```

- ### HTMLで指定する場合

  イベント名の先頭に `on` を付ける
  ```html
  <button onclick="console.log('クリックされました')">クリック</button>
  ```

## 引数
`(e)` または `(event)`：発生したイベントの情報を受け取る引数  
イベントの情報を利用する場合に使用する（使用しない場合は省略できる）
```js
イベントの登録先.addEventListener("イベント", function (e) {
  関数の内容;
});
```
```js
イベントの登録先.addEventListener("イベント", (e) => {
  関数の内容;
});
```

| プロパティ・メソッド    | 意味                                   |
| ----------------------- | -------------------------------------- |
| `e.type`                | イベント名                             |
| `e.key`                 | キーボードイベントで押されたキーの情報 |
| `e.target`              | イベントが発生した要素                 |
| `e.target.value`        | 対象要素の値（入力欄や選択欄など）     |
| `e.target.checked`      | チェックボックスなどのチェック状態     |
| `e.target.value.length` | 入力値の文字数                         |
| `e.currentTarget`       | イベントリスナーを登録した要素         |
| `e.preventDefault()`    | 標準の動作をキャンセル                 |
| `e.stopPropagation()`   | イベントの伝播を停止                   |

- ### イベント名（`e.type`）
  ```js
  input.addEventListener("keydown", (e) => {
    result.textContent += e.type;  // 任意のキーを押す => keydown
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="name">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("name");
  const result = document.getElementById("result");

  input.addEventListener("keydown", (e) => {
    result.textContent += e.type;
  });
  ```
  -->

  ⚠ 引数を指定しない場合、`e` が定義されないため `e.type` は利用できない
  ```js
  input.addEventListener("keydown", () => {
    result.textContent += e.type;
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="name">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("name");
  const result = document.getElementById("result");

  input.addEventListener("keydown", () => {
    result.textContent += e.type;
  });
  ```
  -->
  ---

- ### キーボードで押されたキーの情報（`e.key`）
  ```js
  input.addEventListener("keydown", (e) => {
    result.textContent += `[key: ${e.key}]`;  // Enter キーを押す => [key: Enter]
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="name">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("name");
  const result = document.getElementById("result");

  input.addEventListener("keydown", (e) => {
    result.textContent += `[key: ${e.key}]`;
  });
  ```
  -->
  ---

- ### イベントが発生した要素（`e.target`）
  ```js
  input.addEventListener("input", (e) => {
    result.textContent += `[target: ${e.target}]`;  // => [target: [object HTMLInputElement]]
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="name">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("name");
  const result = document.getElementById("result");

  input.addEventListener("input", (e) => {
    result.textContent += `[target: ${e.target}]`;
  });
  ```
  -->

  - イベントが発生した要素の入力値を取得（`e.target.value`）

    `input`、`textarea`、`select` など、`value` プロパティを持つ要素で使用できる  
    `e.target.checked`、`e.target.value.length`、`e.target.tagName` なども使用できる  
    `e.target.length` は、対象要素がそのプロパティを持つ場合に使用できる
    ```js
    input.addEventListener("input", (e) => {
      result.textContent += e.target.value;  // 「s」と入力 => s
      // 現在の入力値だけを表示する場合は、+= を = に変更
    });
    ```
    <!-- demo
    ```html
    <input type="text" id="name">
    <div id="result"></div>
    ```

    ```js
    const input = document.getElementById("name");
    const result = document.getElementById("result");

    input.addEventListener("input", (e) => {
      result.textContent += e.target.value;
    });
    ```
    -->
  ---

- ### イベントリスナーを登録した要素（`e.currentTarget`）
  例：`e.target` は実際にイベントが発生した要素、`e.currentTarget` はイベントリスナーを登録した要素
  ```html
  <div id="parent" style="background: red;">
    <button id="child">クリック</button>
  </div>
  <div id="result"></div>
  ```
  ```js
  parent.addEventListener("click", (e) => {
    result.textContent =
      `target: ${e.target.tagName}, currentTarget: ${e.currentTarget.tagName}`;
    // 親要素をクリック => target: DIV, currentTarget: DIV
    // 子要素のボタンをクリック => target: BUTTON, currentTarget: DIV
  });
  ```
  <!-- demo
  ```js
  const parent = document.getElementById("parent");
  const result = document.getElementById("result");

  parent.addEventListener("click", (e) => {
    result.textContent =
      `target: ${e.target.tagName}, currentTarget: ${e.currentTarget.tagName}`;
  });
  ```
  -->


## イベント

- ### 主要なイベント一覧

  | イベント名        | 発生条件                                           | 主な登録先                |
  | ----------------- | -------------------------------------------------- | ------------------------- |
  | キーボード系      |                                                    |                           |
  | `keydown`         | キーが押された時                                   | Element, Document, Window |
  | `keyup`           | キーが離された時                                   | Element, Document, Window |
  | `keypress`        | 文字を入力できるキーが押された時（⚠ 非推奨）      | Element, Document         |
  | マウス操作系      |                                                    |                           |
  | `click`           | クリックされた時                                   | Element                   |
  | `dblclick`        | ダブルクリックされた時                             | Element                   |
  | `mousedown`       | マウスボタンが押された時                           | Element                   |
  | `mouseup`         | マウスボタンが離された時                           | Element                   |
  | `mousemove`       | マウスポインタが動いた時                           | Element                   |
  | `mouseover`       | マウスポインタが要素内に入った時（子要素にも適用） | Element                   |
  | `mouseout`        | マウスポインタが要素外へ出た時（子要素にも適用）   | Element                   |
  | フォーカス系      |                                                    |                           |
  | `focus`           | フォーカスされた時                                 | Element                   |
  | `blur`            | フォーカスが失われた時                             | Element                   |
  | フォーム系        |                                                    |                           |
  | `submit`          | フォームが送信された時                             | HTMLFormElement           |
  | `reset`           | フォームがリセットされた時                         | HTMLFormElement           |
  | `change`          | フォーム部品などの値が確定・変更された時           | Element                   |
  | `input`           | 入力値が変更された時                               | Element                   |
  | ドキュメント系    |                                                    |                           |
  | `selectionchange` | 選択範囲が変化された時                             | Document                  |
  | その他            |                                                    |                           |
  | `copy`            | コピーされた時                                     | Element, Document, Window |
  | `paste`           | 貼り付けされた時                                   | Element, Document, Window |

## 要素の属性の値を取得（`Attribute`）
| メソッド                       | 意味                 |
| ------------------------------ | -------------------- |
| `getAttribute("属性名")`       | 属性の値を取得       |
| `hasAttribute("属性名")`       | 属性が存在するか確認 |
| `setAttribute("属性名", "値")` | 属性の値を設定・変更 |
| `removeAttribute("属性名")`    | 属性を削除           |

例
```html
<input type="text" id="name" value="初期値">
```

- ### 属性の値を取得（`get`）
  `変数名.getAttribute("属性名")`
  ```js
  // id名が「name」の要素を取得
  const input = document.getElementById("name");
  // value属性の値を取得
  const valueName = input.getAttribute("value");

  console.log(valueName); // => 初期値
  ```
  <!-- demo
  ```html
  <input type="text" id="name" value="初期値">
  ```
  -->
  ---

- ### 属性が存在するか確認（`has`）
  `変数名.hasAttribute("属性名")`：存在する（`true`）・存在しない（`false`）
  ```js
  // id名が「name」の要素を取得
  const input = document.getElementById("name");
  // value属性が存在するか
  const isExist = input.hasAttribute("value");

  console.log(isExist); // => true
  ```
  <!-- demo
  ```html
  <input type="text" id="name" value="初期値">
  ```
  -->
  ---

- ### 属性の値を設定・変更
  - HTML属性自体を設定・変更する場合（`set`）

    `変数名.setAttribute("属性名", "値")`
    ```js
    // id名が「name」の要素を取得
    const input = document.getElementById("name");
    // ★ value属性の値を「入力値」に変更
    input.setAttribute("value", "入力値");

    console.log(input.outerHTML);
    // => <input type="text" id="name" value="入力値">
    ```
    <!-- demo
    ```html
    <input type="text" id="name" value="入力値">
    ```
    -->

  - DOM要素のプロパティを設定・変更する場合
  
    `変数名.属性名 = "値"`
    ```js
    // id名が「name」の要素を取得
    const input = document.getElementById("name");
    // ★ valueプロパティの値を「設定値」に変更（HTMLは変化しない）
    input.value = "設定値";

    console.log(input.outerHTML);
    // => <input type="text" id="name" value="初期値">
    ```
    <!-- demo
    ```html
    <input type="text" id="name" value="初期値">
    ```
    -->
  ---

- ### 属性を削除（`remove`）
  `変数名.removeAttribute("属性名")`
  ```js
  // id名が「name」の要素を取得
  const input = document.getElementById("name");
  // value属性を削除
  input.removeAttribute("value");

  console.log(input.outerHTML);
  // => <input type="text" id="name">
  ```
  <!-- demo
  ```html
  <input type="text" id="name" value="初期値">
  ```
  -->

## クラス属性の操作（`classList`）
`変数名.classList.メソッド（"クラス名"）`
| メソッド            | 意味                          |
| ------------------- | ----------------------------- |
| `add("A")`          | Aを追加                       |
| `contains("A")`     | Aが存在するか確認             |
| `toggle("A")`       | Aがあれば削除し、無ければ追加 |
| `replace("A", "B")` | AをBに置換                    |
| `remove("A")`       | Aを削除                       |

```html
<button id="button" class="active">クリック</button>
```

- ### 追加（`add`）
  `変数名.classList.add("クラス名")`

  複数の場合、`変数名.classList.add("A", "B")` のようにカンマ（`,`）で区切る 
  ```js
  const btn = document.getElementById("button");

  btn.addEventListener("click", function () {
    // ボタンをクリックすると、変数名「btn」のHTMLのクラス属性に「is-true」が追加される
    btn.classList.add("is-true");
    console.log(btn.outerHTML);
    // => <button id="button" class="active is-true">クリック</button>
  });
  ```
  <!-- demo
  ```html
  <button id="button" class="active">クリック</button>
  ```
  -->
  ---

- ### 存在を確認（`contains`）
  `変数名.classList.contains("クラス名")`：存在する（`true`）・存在しない（`false`）
  ```js
  const btn = document.getElementById("button");
  // 変数名「btn」にクラス名「is-true」が存在するか確認
  const isExist = btn.classList.contains("is-true");

  console.log(isExist); // 存在しない => false
  ```
  <!-- demo
  ```html
  <button id="button" class="active">クリック</button>
  ```
  -->
  ---

- ### あれば削除、なければ追加（`toggle`）
  `変数名.classList.toggle("クラス名")`
  ```js
  const btn = document.getElementById("button");

  btn.addEventListener("click", function () {
    // ボタンをクリックすると、変数名「btn」のHTMLのクラス属性に「is-true」が追加される
    // 再度クリックすると、「is-true」が削除
    btn.classList.toggle("is-true");
    console.log(btn.outerHTML);
    // => <button id="button" class="active is-true">クリック</button>
    // 再度 => <button id="button" class="active">クリック</button>
  });
  ```
  <!-- demo
  ```html
  <button id="button" class="active">クリック</button>
  ```
  -->
  ---

- ### 置換（`replace`）
  `変数名.classList.replace("クラス名A", "クラス名B")`
  ```js
  const btn = document.getElementById("button");

  btn.addEventListener("click", function () {
    // ボタンをクリックすると、変数名「btn」のHTMLのクラス属性に「active」が「is-true」に置換
    btn.classList.replace("active", "is-true");
    console.log(btn.outerHTML);
    // => <button id="button" class="is-true">クリック</button>
  });
  ```
  <!-- demo
  ```html
  <button id="button" class="active">クリック</button>
  ```
  -->
  ---

- ### 削除（`remove`）
  `変数名.classList.remove("クラス名")`
  ```js
  const btn = document.getElementById("button");

  btn.addEventListener("click", function () {
    // ボタンをクリックすると、変数名「btn」のHTMLのクラス属性の「active」を削除
    btn.classList.remove("active");
    console.log(btn.outerHTML);
    // => <button id="button" class="">クリック</button>
  });
  ```
  <!-- demo
  ```html
  <button id="button" class="active">クリック</button>
  ```
  -->
  ---

## DOM要素のプロパティの設定

- `変数名.id = "値"`：id属性に値を設定
- `変数名.className = "値"`：class属性全体に値を設定し直す
  - 複数の場合、`変数名.className = "A B"` のように半角スペースで区切る（id属性の値は1つなので不要） 

  | プロパティ  | 操作                   | 複数の場合                               |
  | ----------- | ---------------------- | ---------------------------------------- |
  | `classList` | クラスを個別に操作     | 複数の引数（カンマ）で指定（`"A", "B"`） |
  | `className` | クラス全体を設定し直す | 半角スペース区切り（`"A B"`）            |

```html
<div>タイトル</div>
```
```js
const el = document.querySelector("div");

// id属性に「title」を設定
el.id = "title";

// クラス属性に「is-true」と「active」を設定
el.className = "is-true active";

console.log(el.outerHTML);
```

## DOM要素のCSSスタイルの取得・設定

JavaScriptの `style` でCSSプロパティを指定する場合、CSSのプロパティ名と異なることがある  
＊ハイフンを削除し、ハイフンの次の文字を大文字にする

| CSS                | JavaScript          |
| ------------------ | ------------------- |
| `color`            | `color`             |
| `font-size`        | * `fontSize`        |
| `text-align`       | * `textAlign`       |
| `background-color` | * `backgroundColor` |


- ### スタイルを取得
  - インラインスタイルのみ取得する場合

    `変数名.style.プロパティ名`
    ```html
    <div id="title" style="background-color: red;">タイトル</div>
    ```
    ```js
    const el = document.getElementById("title");

    const styleValue = el.style.backgroundColor;
    console.log(styleValue);    // => red
    ```
    <!-- demo -->

  - すべてのスタイルを取得する場合：`<style>` や外部CSSファイルなどで指定されたスタイルも対象

    `window.getComputedStyle(変数名)`：実際に適用されているスタイルのプロパティを取得。戻り値から、個々のプロパティの値を取得（スタイルを取得したい場合は、`getPropertyValue` も使用する）
    ```html
    <div id="title" style="background-color: red;">タイトル</div>
    ```
    ```js
    const el = document.getElementById("title");
    ```

    <!-- demo -->

- ### 行の追加・削除
|                |                                      |                                          |
| -------------- | ------------------------------------ | ---------------------------------------- |
| 行＆セルを追加 | `= insertRow(n)` → `= insertCell(n)` | セットで使用                             |
| 行を削除       | `.deleteRow(n)`                      |                                          |
| 行を取得       | `.rows[n]`                           |                                          |
| セルを取得     | `.rows[n]`   →   `.cells[n]`         | セットで使用（`.rows[n].cells[n]`）      |
| セルを削除     | `.rows[n]`       → `.deleteCell(n)`  | セットで使用（`.rows[n].deleteCell(n)`） |

|  `(0)`   | 先頭          |

  - イベントリスナー

    ```js
    const chk1 = document.querySelector("input");
    ```

# 非同期処理
- ### 同期処理のように書く（`async` / `await`）
  関数内で `await` を使用する場合、基本的にその関数に `async` を付ける
  - `async`：関数を非同期関数として定義
  - `await`：Promiseの処理が完了するまで待ち、その結果を取得
  - `await` の後の処理は、Promiseの処理が完了してから実行される
  ```js
  async function getData() {
    const response = await fetch("https://...");
    console.log("通信完了後に実行");
  }
  ```


# Fetch
ファイルやWeb APIなどからデータを取得するために使う機能

## 基本（`fetch`）
  `fetch(URL)`：URLからファイルを取得

  - `fetch()` は Promise を返す非同期処理
  - `async` 関数内で `await` を使うと、レスポンスの取得を待ってから次の処理を実行できる
  - そのため、基本は `async` / `await` を使用して、通信完了後に実行

  ```js
  async function 関数名() {
    const response = await fetch("https://...");
  }

  関数名();
  ```

## レスポンス

- ### データの取得が成功したか確認
  `変数名.ok`：HTTPステータスコードが200～299（成功）なら `true`、それ以外（失敗）なら `false`
  ```js
  async function fetchData() {
    const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv_book.csv");
    console.log(response.ok);
  }

  fetchData();  // => true
  ```
  <!-- demo -->
  - 失敗なら `false`（HTTP エラーと通信エラーは別）
    ```js
    async function fetchData() {
      const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv.csv");
      console.log(response.ok);
    }

    fetchData();  // => false
    ```
    <!-- demo -->

- ### レスポンスコードを返す
  `変数名.status`：HTTPステータスコード（例：`200`、`404`）
  ```js
  async function fetchData() {
    const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv_book.csv");
    console.log(response.status);
  }

  ```
  <!-- demo -->

  - 失敗なら `404` など
    ```js
    async function fetchData() {
      const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv.csv");
      console.log(response.status);
    ```

    <!-- demo -->

## 内容を取得
`await` を使用

- ### 文字列として取得
  `await 変数名.text()`
  - CSVの場合：取得した文字列を行や列に分割する処理は、別途必要
    ```js
    async function fetchData() {
      const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv_book.csv");
      console.log(await response.text());
    }

    fetchData();
    // => カバーURL,タイトル,著者,ステータス,終了日 https://thumb...省略,コンビニ人間,村田 沙耶香,読了,2023/11/08 https://thumb...省略
    ```
    <!-- demo -->

  - HTTP エラーでも、レスポンス本文を取得できる（本文の内容はサーバーによって異なる）

    ```js
    async function fetchData() {
      const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv.csv");
      console.log(await response.text());
    }

    fetchData();
    // => 404: Not Found
    ```
    <!-- demo -->


- ### JSONとして取得
  `await 変数名.json()`：JSON として解析する
  ```js
  async function fetchData() {
    const response = await fetch("https://api.github.com/users/octocat");
    console.log(await response.json());
  }

  fetchData();
  // => {"login":"octocat","id":583231,...省略
  ```
  <!-- demo -->

  - JSON として解析できない（例：JSONファイル以外）場合、`SyntaxError` が発生し、`Promise` が `reject` される
    ```js
    async function fetchData() {
      const response = await fetch("https://raw.githubusercontent.com/aynsze/Code-Reference/refs/heads/main/assets/sample_csv_book.csv");
      console.log(await response.json());

    // => JSONとして解析されないため、エラー
    ```
