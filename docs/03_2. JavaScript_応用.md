# イベントリスナー
`イベントの登録先.addEventListener("イベント", 関数名);`

## イベントの登録先
| イベントの登録先 | 対象                   | 例                           | 要素の取得 |
| ---------------- | ---------------------- | ---------------------------- | ---------- |
| `window`         | ブラウザのウィンドウ   | ウィンドウのサイズ変更を監視 | 不要       |
| `document`       | ドキュメント全体       | ページ内のクリックを監視     | 不要       |
| `element` *      | 取得した特定のHTML要素 | 特定のボタンのクリックを監視 | 通常は必要 |

＊ `イベントの登録先` に対して、HTML要素を取得した場合は、その要素を格納した `変数名` を指定できる


## 指定方法
- ### 関数名を指定する場合
    ```js
    イベントの登録先.addEventListener("イベント", 関数名);
    ```
    例：ドキュメント全体に対して、関数名を指定
    ```js
    function showMessage() {
      console.log("クリックされました");
    }

    document.addEventListener("click", showMessage);
    ```
    <!-- demo -->


- ### 関数を直接指定する場合
  - 通常の関数（無名関数）
    ```js
    イベントの登録先.addEventListener("イベント", function () {
      関数の内容;
    });
    ```
    例：取得したHTML要素に対して、関数を直接指定
    ```js
    const btn = document.getElementById("button");

    btn.addEventListener("click", function () {
      console.log("クリックされました");
    });
    ```
    <!-- demo 
    ```html
    <button id="button">クリック</button>
    ```
    -->

  - アロー関数（`=>`）
    ```js
    イベントの登録先.addEventListener("イベント", () => {
      関数の内容;
    });
    ```

- ### HTMLで指定する場合

  イベント名の先頭に `on` を付ける
  ```html
  <button onclick="console.log('クリックされました')">クリック</button>
  ```

## 引数
`(e)` または `(event)`：発生したイベントの情報を受け取る引数  
イベントの情報を利用する場合に使用する（使用しない場合は省略できる）
```js
イベントの登録先.addEventListener("イベント", function (e) {
  関数の内容;
});
```
```js
イベントの登録先.addEventListener("イベント", (e) => {
  関数の内容;
});
```

| プロパティ・メソッド | 意味 |
| --- | --- |
| `e.type` | イベント名 |
| `e.key` | キーボードイベントで押されたキーの情報 |
| `e.target` | イベントが発生した要素 |
| `e.target.value` | 対象要素の値（入力欄や選択欄など） |
| `e.target.checked` | チェックボックスなどのチェック状態 |
| `e.target.value.length` | 入力値の文字数 |
| `e.currentTarget` | イベントリスナーを登録した要素 |
| `e.preventDefault()` | 標準の動作をキャンセル |
| `e.stopPropagation()` | イベントの伝播を停止 |

- ### イベント名（`e.type`）
  ```js
  input.addEventListener("keydown", (e) => {
    result.textContent += e.type;  // 任意のキーを押す => keydown
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="input">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("input");
  const result = document.getElementById("result");

  input.addEventListener("keydown", (e) => {
    result.textContent += e.type;
  });
  ```
  -->

  ⚠ 引数を指定しない場合、`e` が定義されないため `e.type` は利用できない
  ```js
  input.addEventListener("keydown", () => {
    result.textContent += e.type;
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="input">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("input");
  const result = document.getElementById("result");

  input.addEventListener("keydown", () => {
    result.textContent += e.type;
  });
  ```
  -->
  ---

- ### キーボードで押されたキーの情報（`e.key`）
  ```js
  input.addEventListener("keydown", (e) => {
    result.textContent += `[key: ${e.key}]`;  // Enter キーを押す => [key: Enter]
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="input">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("input");
  const result = document.getElementById("result");

  input.addEventListener("keydown", (e) => {
    result.textContent += `[key: ${e.key}]`;
  });
  ```
  -->
  ---

- ### イベントが発生した要素（`e.target`）
  ```js
  input.addEventListener("input", (e) => {
    result.textContent += `[target: ${e.target}]`;  // => [target: [object HTMLInputElement]]
  });
  ```
  <!-- demo
  ```html
  <input type="text" id="input">
  <div id="result"></div>
  ```

  ```js
  const input = document.getElementById("input");
  const result = document.getElementById("result");

  input.addEventListener("input", (e) => {
    result.textContent += `[target: ${e.target}]`;
  });
  ```
  -->

  - イベントが発生した要素の入力値を取得（`e.target.value`）

    `input`、`textarea`、`select` など、`value` プロパティを持つ要素で使用できる  
    `e.target.checked`、`e.target.value.length`、`e.target.tagName` なども使用できる  
    `e.target.length` は、対象要素がそのプロパティを持つ場合に使用できる
    ```js
    input.addEventListener("input", (e) => {
      result.textContent += e.target.value;  // => 「s」と入力 => s
      // 現在の入力値だけを表示する場合は、+= を = に変更
    });
    ```
    <!-- demo
    ```html
    <input type="text" id="input">
    <div id="result"></div>
    ```

    ```js
    const input = document.getElementById("input");
    const result = document.getElementById("result");

    input.addEventListener("input", (e) => {
      result.textContent += e.target.value;
    });
    ```
    -->
  ---

- ### イベントリスナーを登録した要素（`e.currentTarget`）
  例：`e.target` は実際にイベントが発生した要素、`e.currentTarget` はイベントリスナーを登録した要素
  ```html
  <div id="parent" style="background: red;">
    <button id="child">クリック</button>
  </div>
  <div id="result"></div>
  ```
  ```js
  parent.addEventListener("click", (e) => {
    result.textContent =
      `target: ${e.target.tagName}, currentTarget: ${e.currentTarget.tagName}`;
      // 親要素をクリック => target: DIV, currentTarget: DIV
      // 子要素のボタンをクリック => target: BUTTON, currentTarget: DIV
  });
  ```
  <!-- demo
  ```js
  const parent = document.getElementById("parent");
  const result = document.getElementById("result");

  parent.addEventListener("click", (e) => {
    result.textContent =
      `target: ${e.target.tagName}, currentTarget: ${e.currentTarget.tagName}`;
  });
  ```
  -->




## 非同期処理
- ### 同期処理のように書く（`async` / `await`）
  関数内で `await` を使用する場合、基本的にその関数に `async` を付ける
  - `async`：関数を非同期関数として定義
  - `await`：Promiseの処理が完了するまで待ち、その結果を取得
  - `await` の後の処理は、Promiseの処理が完了してから実行される
  ```js
  async function getData() {
    const response = await fetch("https://...");
    console.log("通信完了後に実行");
  }
  ```
