# 基本
`"変数名": 値`：変数名と値をコロン（`:`）で区切る

文字列は、ダブルクォーテーション（`"`）で囲む

## 記述方法
- ### 1つだけ記述
  ```json
  {
    "name": "Tanaka"
  }
  ```
  ---

- ### 複数記述
  カンマ（`,`）で連結
  ```json
  {
    "name": "Tanaka",
    "age": 26
  }
  ```
  ---

- ### 階層構造（オブジェクト）
  ```json
  {
    "user_info": {
      "name": "Tanaka",
      "age": 26
    }
  }
  ```
  ---

- ### 配列（`[]`）
  `"変数名": [値1, 値2, 値3]`
  ```json
  {
    "color_list": [
      "red",
      "green",
      "blue"
    ],
    "num_list": [
      123,
      456,
      789
    ],
    "object_list": [
      {
        "name": "Tanaka",
        "age": 26
      },
      {
        "name": "Suzuki",
        "age": 32
      }
    ]
  }
  ```
