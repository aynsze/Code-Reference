# 基本

## 正規表現

`/正規表現/` ：スラッシュ（`/`）で囲む

| 正規表現 | 意味            |
| -------- | --------------- |
| `^x`     | xで始まる文字列 |
| `x$`     | xで終わる文字列 |

## 特殊文字

| 表現 | 意味 |
| ---- | ---- |
| `\n` | 改行 |

## フラグ

`/正規表現/フラグ` ：スラッシュ（`/`）で囲んだ正規表現の後ろに記載

| フラグ           | 使い方               | 意味                                                     |
| ---------------- | -------------------- | -------------------------------------------------------- |
| `i` (ignoreCase) | `/x/i` <!-- copy --> | [大文字・小文字を区別しない](#大文字小文字を区別しないi) |

- ### 大文字・小文字を区別しない（`i`）

  ```js
  /ABC/.test("abc"); // false
  ```

  <!-- demo -->

  ```js
  /ABC/i.test("abc"); // true
  ```
