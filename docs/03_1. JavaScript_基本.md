# 基本
## 変数

- ### 変数の宣言方法
  | 変数                    | 説明     |
  | ----------------------- | -------- |
  | `let 変数名`            | 再代入◎  |
  | `const 変数名 = 初期値` | 再代入✖ |

  - 記述方法
    ```js
    let width;
    ```
    複数の場合は、カンマ（`,`）で区切る
    ```js
    // let 変数名1, 変数名2,
    let width, height;
    ```
    上記の場合は、以下と同じ
    ```js
    let width;
    let height;
    ```

    `const` も同じ
    ```js
    // const 変数名1 = 初期値1, 変数名2 = 初期値2;
    const maxWidth = 720, minWidth = 320;
    ```
    上記の場合は、以下と同じ
    ```js
    const maxWidth = 720;
    const minWidth = 320;
    ```

  - 再代入について

    `let`：再代入可能 = あとで変えられる
    ```js
    let age = 20;
    age = 50; // 再代入可能なので「50」になる
    console.log(age); // => 50
    ```
    <!-- demo -->

    `const`：再代入不可 = 変えられない、宣言時に初期値が必要
    ```js
    const age = 20;
    age = 50; // 再代入不可なので、TypeError が発生
    console.log(age); // この行は実行されない
    ```
    <!-- demo -->

- ### インクリメント
  | 種類 | 説明             | 演算子     |
  | :--: | ---------------- | ---------- |
  | 前置 | 増やしてから使う | `++変数名` |
  |      | 減らしてから使う | `--変数名` |
  | 後置 | 使ってから増やす | `変数名++` |
  |      | 使ってから減らす | `変数名--` |

  前置インクリメント
    - 増やしてから使う（`++変数名`）
      ```js
      a = 5;
      console.log(++a);   // 5 + 1 = 6
      ```
      <!-- demo -->

    - 減らしてから使う（`--変数名`）
      ```js
      a = 5;
      console.log(--a);   // 5 - 1 = 4
      ```
      <!-- demo -->
    ---

  後置インクリメント
    - 使ってから増やす（`変数名++`）
      ```js
      a = 5;
      a++;    // 5 + 1 で6になる
      console.log(a);   // 6
      ```
      <!-- demo -->
      ⚠ 以下では、使用されていないため、そのまま
      ```js
      a = 5;
      console.log(a++);   // 5
      ```
      <!-- demo -->

    - 使ってから減らす（`変数名--`）
      ```js
      a = 5;
      a--;    // 5 - 1 で4になる
      console.log(a);   // 4
      ```
      <!-- demo -->
  ---

- ### 比較演算子
  | 型変換 | 説明             | 比較演算子 |
  | :----: | ---------------- | ---------- |
  |  あり  | 等しい           | `==`       |
  |        | 等しくない       | `!=`       |
  |  なし  | 厳密に等しい     | `===`      |
  |        | 厳密に等しくない | `!==`      |

  型変換あり：型が異なる場合（文字列 vs 数値など）でも、必要に応じて型変換して比較
    - 等しい
      ```js
      5 == "5"    // true
      ```
      <!-- demo -->

    - 等しくない
      ```js
      5 != "5"    // false
      ```
      <!-- demo -->

  型変換なし：型変換せずに比較（おすすめ）
    - 厳密に等しい
      ```js
      5 === "5"   // 数値の5と文字列の"5"は型が異なるため、等しくない => false
      ```
      <!-- demo -->

      ```js
      5 === 5   // 数値の5と数値の5は等しい => true
      ```
      <!-- demo -->

    - 厳密に等しくない
      ```js
      5 !== "5"   // 数値の5と文字列の"5"は型が異なるため、等しくない => true
      ```
      <!-- demo -->
  ---

  | 割り算     | `/`    | `/=`                 |
  | 割った余り | `%`    | `%=`                 |
  | べき乗     | `**`   | `**=`                |

  - 足し算（数値）

    現在の値に新しい値を追加して、再び代入
    ```js

    message += "keydown ";    // message = message + "keydown "; と同じ
    message += "keyup ";
    console.log(message);   // focus keydown keyup
    ```
    <!-- demo -->

## 文字列の部分取り出し
- ### 空白を取り除く（`trim`）
  - 先頭&末尾の空白を取り除く（`trim`）

    `文字列.trim()`：文字列の先頭および末尾から空白を取り除いた文字列を返す
    ```js
    "   Hello   ".trim();   // 「Hello」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trim());
    ```
    -->

  - 先頭の空白を取り除く（`trimStart`）

    `文字列.trimStart()`：文字列の先頭から空白を取り除いた文字列を返す
    ```js
    "   Hello   ".trimStart();   // 「Hello   」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trimStart());
    ```
    -->

  - 末尾の空白を取り除く（`trimEnd`）

    `文字列.trimEnd()`：文字列の末尾から空白を取り除いた文字列を返す
    ```js
    "   Hello   ".trimEnd();    // 「   Hello」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trimEnd());
    ```
    -->
  ---

- ### 部分文字列を取得
  文字列から開始位置と終了位置を指定して部分文字列を取得
  | メソッド    | x に負の値     | y を省略       |
  | :---------- | :------------- | :------------- |
  | `substring` | 0 として扱う   | x から末尾まで |
  | `slice`     | 末尾から数える | x から末尾まで |
  | `substr`    | 末尾から数える | x から末尾まで |

  例：ABCDEFG
  |  0  |  1  |  2  |  3  |  4  |  5  |  6  |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  |  A  |  B  |  C  |  D  |  E  |  F  |  G  |

  | メソッド          | コード                     | 結果 |
  | :---------------- | :------------------------- | :--- |
  | `substring(2, 4)` | 開始位置2、終了位置4の手前 | CD   |
  | `slice(2, 4)`     | 開始位置2、終了位置4の手前 | CD   |
  | `substr(2, 4)`    | 開始位置2から4文字分       | CDEF |

  - `substring`
    `文字列.substring(x, y)`：0始まりの位置で、xからyの手前までの部分文字列を返す
    ```js
    "ABCDEFG".substring(2, 4);    // => CD
    ```
    <!-- demo -->

    yを省略すると残りのすべてを返す
    ```js
    "ABCDEFG".substring(2);   // => CDEFG
    ```
    <!-- demo -->

    ⚠ xに負の値を指定すると0番目とみなされる
    ```js
    "ABCDEFG".substring(-2, 4);
    // (0, 4)と同じ => ABCD
    ```
    <!-- demo -->

  - `slice`
    `文字列.slice(x, y)`：0始まりの位置で、xからyの手前までの部分文字列を返す
    ```js
    "ABCDEFG".slice(2, 4);   // => CD
    ```
    <!-- demo -->

    yを省略すると残りのすべてを返す
    ```js
    "ABCDEFG".slice(2);   // => CDEFG
    ```
    <!-- demo -->

    ⚠ xに負の値を指定すると後ろから数える
    ```js
    "ABCDEFG".slice(-3, 6);
    // (4, 6)と同じ
    // -3 は末尾から3文字目（E）
    // => EF
    ```
    <!-- demo -->
  ---

- ### 指定した文字数分取り出す（`substr`）
  `文字列.substr(x, y)`：x番目からy文字分の文字列を返す（非推奨）
  ```js
  "ABCDEFG".substr(2, 4);   // => CDEF
  ```
  <!-- demo -->

  yを省略すると残りのすべてを返す
  ```js
  "ABCDEFG".substr(2);    // => CDEFG
  ```
  <!-- demo -->

  ⚠ xに負の値を指定すると後ろから数える
  ```js
  "ABCDEFG".substr(-2, 4);
  // -2 は末尾から2文字目（F）
  // そこから4文字分を取り出すが、残りは FG の2文字
  // => FG
  ```
  <!-- demo -->


## 文字列の分割と連結
- ### 分割（`split`）
  `文字列.split("A", n)`：文字列をAで分割し、最大n個の要素を持つ配列を返す

  `n` は省略可能、省略した場合は、分割結果のすべての要素を返す
  ```js
  "/Jan/Feb/Mar/Apr/May/Jun/".split("/");
  // => ["","Jan","Feb","Mar","Apr","May","Jun",""]
  ```
  <!-- demo -->
  配列の要素数を最大3個に制限する場合
  ```js
  "/Jan/Feb/Mar/Apr/May/Jun/".split("/", 3);
  // => ["","Jan","Feb"]
  ```
  <!-- demo -->

- ### 連結（`concat`）
  `文字列.concat("A", "B")`：文字列にAとBを連結

  ```js
  "ABC".concat("DEF", "GHI");
  // => ABCDEFGHI
  ```
  <!-- demo -->

  - `+` 演算子でも可能

    ```js
    "ABC" + "DEF"   // => ABCDEF
    ```
    <!-- demo -->

- ### 繰り返す（`repeat`）
  `文字列.repeat(n)`：文字列をn回繰り返す（nは、0以上の整数）

  ```js
  "ABC".repeat(3);  //「ABC」を3回繰り返す => "ABCABCABC"
  ```
  <!-- demo -->

  ```js
  "ABC".repeat(0);  // => ""
  ```
  <!-- demo -->

## 文字列を指定の長さに変更
指定した長さになるまで、空白または指定した文字列を追加する

- ### 先頭（`padStart`）
  `文字列.padStart(長さの数値, "追加する文字列")`：先頭に文字列を追加し、指定した長さにする
  ```js
  "ABC".padStart(5, "_");  // => __ABC
  ```
  <!-- demo -->

- ### 末尾（`padEnd`）
  `文字列.padEnd(長さの数値, "追加する文字列")`：末尾に文字列を追加し、指定した長さにする
  ```js
  "ABC".padEnd(5, "_");  // => ABC__
  ```
  <!-- demo -->

- ### その他の仕様
  - `追加する文字列` を省略した場合は、指定した長さになるまで半角スペースを追加
    ```js
    "ABC".padStart(5);  // => "  ABC"
    ```
    <!-- demo 
    ```js
    console.log("ABC".padStart(5));
    ```
    -->

  - 元の文字列が指定した長さ以上の場合、変更されない
    ```js
    "ABC".padStart(2, "_");  // => ABC
    ```
    <!-- demo -->

  - 指定した文字列の一部だけが使われることもある
    ```js
    "ABC".padEnd(5, "DEF");  // => ABCDE
    ```
    <!-- demo -->

| `JSON.stringify(obj)` | JavaScriptの値 → JSON文字列 | `string`                 |
| `JSON.parse(str)`     | JSON文字列 → JavaScriptの値 | `object`                 |

| 種類                           | 違い       | 例                               |
| ------------------------------ | ---------- | -------------------------------- |
| JSON文字列                     | `"変数名"` | `{"name":"りんご","price":150}`  |
| JavaScriptの値（オブジェクト） | `変数名`   | `{ name: "りんご", price: 150 }` |

- ### オブジェクトをJSON文字列に変換（`stringify`）
  `JSON.stringify(値)`：JavaScriptのオブジェクトをJSON文字列に変換する
  ```js
  const obj = { name: "りんご", price: 150 };
  const json = JSON.stringify(obj);

  console.log(json);
  // => {"name":"りんご","price":150}

  console.log(json.name);   // => 出力されない（undefined）
  ```
  <!-- demo -->

  - 整形

    `JSON.stringify(値, null, n)`：`n` は、インデントのスペース数
    ```js
    const obj = { name: "りんご", price: 150 };
    // インデントのスペース数を2
    const json = JSON.stringify(obj, null, 2);

    console.log(json);
    // {
    //   "name": "りんご",
    //   "price": 150
    // }
    ```
    <!-- demo -->
  ---

- ### JSON文字列をJavaScriptの値に変換（`parse`）
  `JSON.parse(JSON文字列)`：JSON文字列をJavaScriptのオブジェクトに変換する
  ```js
  const json = '{"name":"りんご","price":150}';
  const obj = JSON.parse(json);

  console.log(obj);
  // => { name: "りんご", price: 150 }

  console.log(typeof obj);  // => object
  console.log(obj.name);    // => りんご
  ```
  <!-- demo -->

# 条件分岐
## if文
- ### 基本（`if`）
  - true のみの場合（`if`）
    ```js
    if (条件) {
      条件がtrueの場合に実行する処理
    }
    ```
    例：scoreが70以上なら「おめでとう」と出力
    ```js
    const score = 70;

    // 変数名「score」が70以上かどうかを判定する
    if (score >= 70) {
      // 変数名「score」が70以上の場合に実行する処理
      console.log("おめでとう");
    }

    // => おめでとう
    ```
    <!-- demo -->

  - trueとfalseの場合（`if ~ else`）
    ```js
    if (条件) {
      条件がtrueの場合に実行する処理
    } else {
      条件がfalseの場合に実行する処理
    }
    ```
    例：scoreが70以上なら「おめでとう」、それ以外なら「残念」と出力
    ```js
    const score = 60;

    // 変数名「score」が70以上かどうかを判定する
    if (score >= 70) {
      // 変数名「score」が70以上の場合に実行する処理
      console.log("おめでとう");
    } else {
      // 変数名「score」が70以上ではない場合に実行する処理
      console.log("残念");
    }

    // => 残念
    ```
    <!-- demo -->
  ---

- ### 省略バージョン
  各分岐の処理がそれぞれ1つの文だけの場合は、`{}` を省略できる
  ```js
  const score = 60;

  if (score >= 70)
    console.log("おめでとう");
  else
    console.log("残念");

  // => 残念
  ```
  <!-- demo -->

  1行で記述することもできる
  ```js
  const score = 70;

  if (score >= 70) console.log("おめでとう");
  else console.log("残念");

  // => おめでとう
  ```
  <!-- demo -->
  ---

- ### 複数の条件
  - 複数の条件（`if ~ else if ~ else`）
    ```js
    if (条件1) {
      条件1がtrueの場合に実行する処理
    } else if (条件2) {
      条件1がfalseで、条件2がtrueの場合に実行する処理
    } else {
      すべての条件がfalseの場合に実行する処理
    }
    ```

    ```js
    const score = 100;

    // 変数名「score」が100かどうかを判定する
    if (score === 100) {
      // 変数名「score」が100の場合に実行する処理
      console.log("満点！");
    } else if (score >= 70) {
      // 変数名「score」が100ではなく、70以上の場合に実行する処理
      console.log("おめでとう");
    } else {
      // 変数名「score」が100でも70以上ではない場合に実行する処理
      console.log("残念");
    }

    // => 満点！
    ```
    <!-- demo -->

  - 条件の入れ子（`if` の中に `if`）
    ```js
    if (条件1) {
      条件1がtrueの場合に実行する処理

      if (条件2) {
        条件1がtrueで、条件2がtrueの場合に実行する処理
      } else {
        条件1がtrueで、条件2がfalseの場合に実行する処理
      }
    } else {
      条件1がfalseの場合に実行する処理
    }
    ```
    ```js
    const score = 80;

    // 変数名「score」が70以上かどうかを判定する
    if (score >= 70) {
      // 変数名「score」が70以上の場合に実行する処理
      console.log("よく頑張った");

      if (score === 100) {
        // 70以上の中でも「score」が100の場合に実行する処理
        console.log("満点！");
      } else {
        // 70以上の中でも「score」が100ではない場合に実行する処理
        console.log("おめでとう");
      }
    } else {
      // 変数名「score」が70以上ではない場合に実行する処理
      console.log("残念");
    }

    // => よく頑張った
    // => おめでとう
    ```
    <!-- demo -->

## switch文
複数の値との一致を `===` 演算子で判定する場合は、`switch` 文を使用した条件分岐がおすすめ

- ### 基本（`switch`）
  ```js
  switch (条件の変数名) {
    case 条件の値1:
      条件の変数名 === 条件の値1の場合に実行する処理
      break;

    case 条件の値2:
      条件の変数名 === 条件の値2の場合に実行する処理
      break;

    default:
      式がいずれの値とも一致しない場合に実行する処理
  }
  ```
  例
  ```js
  const score = 40;

  switch (score) {
    case 100:
      console.log("満点！");
      break;

    case 40:
      console.log("もう少し頑張ろう");
      break;

    default:
      console.log("残念");
  }
  // => もう少し頑張ろう
  ```
  <!-- demo -->

  以下の `if` 文と同じ
  ```js
  const score = 40;

  if (score === 100) {
    console.log("満点！");
  } else if (score === 40) {
    console.log("もう少し頑張ろう");
  } else {
    console.log("残念");
  }
  // => もう少し頑張ろう
  ```
  <!-- demo -->
  ---

- ### break文を記述しなかった場合
  一致した `case` から順にすべて実行される
  ```js
  const score = 100;

  switch (score) {
    case 100:
      console.log("満点！");
    // break;

    case 40:
      console.log("もう少し頑張ろう");
    // break;

    default:
      console.log("残念");
  }
  // => 満点！
  // => もう少し頑張ろう
  // => 残念
  ```
  <!-- demo -->


# 関数
何度も使いたい処理をまとめておく箱

```js
function 関数名(引数1, 引数2, ...) {
  実行される処理1;
  実行される処理2;
  ...

  return 戻り値;
}
```

## 関数の定義と使用

- ### 基本（`function`）

  定義
  ```js
  function 関数名() {
    処理...;
  }
  ```

  以下の場合、まだ関数を呼んでいないので実行されない
  ```js
  // 関数名「greet」を定義する
  function greet() {
    // 関数名「greet」の処理
    console.log("Hello");
  }
  ```
  <!-- demo -->

  使用
  ```js
  関数名();
  ```
  以下の場合、呼び出ししているので、使用される
  ```js
  // 関数名「greet」を定義する
  function greet() {
    // 関数名「greet」の処理
    console.log("Hello");
  }

  // 関数名「greet」を呼び出す
  greet();
  ```
  <!-- demo -->
  ---

- ### 引数を利用
  定義：複数ある場合は、カンマ（`,`）で区切る
  ```js
  function 関数名(引数1, 引数2, ...) {
    処理...;
  }
  ```
  使用
  ```js
  関数名(引数1, 引数2, ...);
  ```

  ```js
  // 関数名「score」を定義し、引数「x」と「y」を指定する
  function score(x, y) {
    // 関数名「score」の処理

    // 変数名「sum」では、「x + y」の計算をする
    const sum = x + y;

    // 関数の中で結果を出力
    console.log(sum);
  }

  // 関数名「score」を呼び出し、引数「x」に4、「y」に10を渡す
  score(4, 10);
  // => 14
  ```
  <!-- demo -->
  - `x` と `y` は、関数を定義するときに指定する引数（仮引数）
  - `4` と `10` は、関数を呼び出すときに渡す引数の値（実引数）
  ---

- ### 戻り値を利用（`return`）
  関数内で作成した値を別の関数や呼び出し元で利用するには、必要に応じて `return` で値を返す
  定義
  ```js
  function 関数名() {
    処理...;

    return 戻り値;
  }
  ```

  - `return`：関数の呼び出し元に値を返す（関数の中で作った値を、関数の外で使えるようにする）
  - 戻り値：関数が返す値

  ```js
  // 関数名「score」を定義し、引数「x」と「y」を指定する
  function score(x, y) {
    // 引数「x」と「y」を足した値を返す
    return x + y;
  }

  // 関数名「score」を呼び出し、戻り値を変数名「result」に代入する
  const result = score(4, 10);

  // 変数名「result」の値を出力する
  console.log(result);

  // => 14
  ```
  <!-- demo -->
