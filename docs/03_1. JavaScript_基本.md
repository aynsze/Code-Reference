  Math.floor(-3.6);   // -4

  <!-- demo -->

  Math.round(-3.6);   // -4

- ### インクリメント
  | 種類 | 説明             | 演算子     |
  | :--: | ---------------- | ---------- |
  | 前置 | 増やしてから使う | `++変数名` |
  |      | 減らしてから使う | `--変数名` |
  | 後置 | 使ってから増やす | `変数名++` |
  |      | 使ってから減らす | `変数名--` |

  前置インクリメント
    - 増やしてから使う（`++変数名`）
      ```js
      a = 5;
      console.log(++a);   // 5 + 1 = 6
      ```
      <!-- demo -->

    - 減らしてから使う（`--変数名`）
      ```js
      a = 5;
      console.log(--a);   // 5 - 1 = 4
      ```
      <!-- demo -->
    ---

  後置インクリメント
    - 使ってから増やす（`変数名++`）
      ```js
      a = 5;
      a++;    // 5 + 1 で6になる
      console.log(a);   // 6
      ```
      <!-- demo -->
      ⚠ 以下では、使用されていないため、そのまま
      ```js
      a = 5;
      console.log(a++);   // 5
      ```
      <!-- demo -->

    - 使ってから減らす（`変数名--`）
      ```js
      a = 5;
      a--;    // 5 - 1 で4になる
      console.log(a);   // 4
      ```
      <!-- demo -->
  ---

- ### 比較演算子
  | 型変換 | 説明             | 比較演算子 |
  | :----: | ---------------- | ---------- |
  |  あり  | 等しい           | `==`       |
  |        | 等しくない       | `!=`       |
  |  なし  | 厳密に等しい     | `===`      |
  |        | 厳密に等しくない | `!==`      |

  型変換あり：型が異なる場合（文字列 vs 数値など）でも、必要に応じて型変換して比較
    - 等しい
      ```js
      5 == "5"    // true
      ```
      <!-- demo -->

    - 等しくない
      ```js
      5 != "5"    // false
      ```
      <!-- demo -->

  型変換なし：型変換せずに比較（おすすめ）
    - 厳密に等しい
      ```js
      5 === "5"   // 数値の5と文字列の"5"は型が異なるため、等しくない => false
      ```
      <!-- demo -->

      ```js
      5 === 5   // 数値の5と数値の5は等しい => true
      ```
      <!-- demo -->

    - 厳密に等しくない
      ```js
      5 !== "5"   // 数値の5と文字列の"5"は型が異なるため、等しくない => true
      ```
      <!-- demo -->
  ---

- ### 複合・論理代入演算子
  | 説明       | 演算子 | 複合・論理代入演算子 |
  | ---------- | ------ | -------------------- |
  | 足し算     | `+`    | `+=`                 |
  | 引き算     | `-`    | `-=`                 |
  | 掛け算     | `*`    | `*=`                 |
  | 割り算     | `/`    | `/=`                 |
  | 割った余り | `%`    | `%=`                 |
  | べき乗     | `**`   | `**=`                |

  - 足し算（数値）

    現在の値に新しい値を追加して、再び代入
    ```js
    a = 10;
    a += 3;   // a = a + 3; と同じ
    console.log(a);
    ```
    <!-- demo -->

  - 足し算（文字列）

    現在の結果を取得して、新しい文字列と結合してから代入
    ```js
    let message = "focus ";
    message += "keydown ";    // message = message + "keydown "; と同じ
    message += "keyup ";
    console.log(message);   // focus keydown keyup
    ```
    <!-- demo -->

## 数値

- ### 小数点の設定（`toFixed`）
  `数値.toFixed(桁数)`

  桁数が無記入の場合は、整数
  ```js
  1.2345.toFixed();   // 1
  ```
  <!-- demo -->

  桁数が `2` の場合は、小数点第2位まで表示
  ```js
  const num = 1.2345;
  console.log(num.toFixed(2));    // 1.23
  ```
  <!-- demo -->



# 文字列

## 基本
- ### 文字列の長さを取得（`length`）
  `文字列.length` ：文字列の文字の個数を返す

  ```js
  let address = "東京都";
  console.log(address.length);  // 3
  ```
  <!-- demo -->

  ```js
  "あいうえお".length;  // 5
  ```
  <!-- demo -->
  ---

## 文字列の置換
- ### 通常の置換
  - 最初の1件だけ置換（`replace`）

    `文字列.replace(置換前, 置換後)`

    例：「a pen」のみ「pen」を「book」に置換
    ```js
    "There is a pen, a pencil case, a red pen, and a book.".replace("pen", "book");
    ```
    <!-- demo -->

  - 全件置換（`replaceAll`）

    `文字列.replaceAll(置換前, 置換後)`

    例：「a pen」と「a pencil」と「a red pen」の「pen」を「book」に置換
    ```js
    "There is a pen, a pencil case, a red pen, and a book.".replaceAll("pen", "book");
    ```
    <!-- demo -->
  ---

- ### 大文字・小文字に置換
  - 大文字に置換（`toUpperCase`）

    `文字列.toUpperCase()` ：小文字のアルファベットを大文字に変換した新しい文字列を返す

    ```js
    "Hello".toUpperCase();    // HELLO
    ```
    <!-- demo -->

  - 小文字に置換（`toLowerCase`）

    `文字列.toLowerCase()` ：大文字のアルファベットを小文字に変換した新しい文字列を返す

    ```js
    "Hello".toLowerCase();    // hello
    ```
    <!-- demo -->


## 文字列の部分取り出し
- ### 取り除く（`trim`）
  - 先頭&末尾の空白を取り除く（`trim`）

    `文字列.trim()` ：文字列の先頭および末尾から空白を取り除いた文字列を返す

    ```js
    "   Hello   ".trim();   // 「Hello」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trim());
    ```
    -->

  - 先頭の空白を取り除く（`trimStart`）

    `文字列.trimStart()` ：文字列の先頭から空白を取り除いた文字列を返す

    ```js
    "   Hello   ".trimStart();   // 「Hello   」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trimStart());
    ```
    -->

  - 末尾の空白を取り除く（`trimEnd`）

    `文字列.trimEnd()` ：文字列の末尾から空白を取り除いた文字列を返す

    ```js
    "   Hello   ".trimEnd();    // 「   Hello」
    ```
    <!-- demo 
    ```js
    console.log("   Hello   ".trimEnd());
    ```
    -->

# 配列

## 基本
- ### 配列の作成
  `変数名 = [e1, e2, ...]`：変数名に、e1, e2, ...の要素をもつ配列を作成
  ```js
  // 変数名「color」に、文字列の配列を作成する
  let color = ["Red", "Green", "Blue"];
  ```

  <!-- demo
  ```js
  let color = ["Red", "Green", "Blue"];
  console.log(color);
  ```
  -->
  ---

- ### 配列の個数（`length`）
  `変数名.length`
  ```js
  let color = ["Red", "Green", "Blue"];
  console.log(color.length);    // 3
  ```
  <!-- demo -->

## 配列要素の追加・削除
|      | Aを追加      | 1つを削除 |
| ---- | ------------ | --------- |
| 先頭 | `unshift(A)` | `shift`   |
| 最後 | `push(A)`    | `pop`     |

- ### 要素の追加
  複数要素の場合は、カンマ（`,`）で区切る
  - 先頭にAを追加（`unshift(A)`）

    `変数名.unshift(A)` ：配列の先頭にAを追加
    ```js
    let color = ["Red", "Green", "Blue"];
    color.unshift("色");    // 先頭に「色」を追加

    console.log(color);   // ["色","Red","Green","Blue"]
    ```
    <!-- demo -->
    ⚠ 以下の場合は、配列の個数を返してしまう
    ```js
    let color = ["Red", "Green", "Blue"];
    console.log(color.unshift("色"));   // 4
    ```
    <!-- demo -->

  - 最後にAを追加（`push(A)`）

    `変数名.push(A)` ：配列の最後にAを追加
    ```js
    let color = ["Red", "Green", "Blue"];
    color.push("色", "3色");    // 最後に「色」と「3色」を追加

    console.log(color);   // ["Red","Green","Blue","色","3色"]
    ```
    <!-- demo -->
    ---

- ### 要素の削除
  - 先頭の1つを削除（`shift()`）

    `変数名.shift()` ：配列の先頭の1つを削除
    ```js
    let color = ["Red", "Green", "Blue"];
    color.shift();    // 先頭の1つ（Red）を削除

    console.log(color);   // ["Green","Blue"]
    ```
    <!-- demo -->

  - 最後の1つを削除（`pop()`）

    `変数名.pop()` ：配列の最後の1つを削除
    ```js
    let color = ["Red", "Green", "Blue"];
    color.pop();    // 最後の1つ（Blue）を削除

    console.log(color);   // ["Red","Green"]
    ```
    <!-- demo -->
